## Run against your endpoint

Configure the same variables as [Build with the API](/build-with-the-api):

```bash
export ORCA_BASE_URL="https://api.orcapods.ai/v1"
export ORCA_API_KEY="YOUR_ORCA_KEY"
export ORCA_MODEL="orca/openrouter/YOUR_OPENROUTER_MODEL_ID"
```

Save the example as a file, install the client version pinned in [Build with the API](/build-with-the-api), and run it:

<CodeGroup>
```bash Python
python3 -m venv .venv
source .venv/bin/activate
python -m pip install openai==3.13.0
python example.py
```
```bash TypeScript
npm pkg set type=module
npm install openai@7.15.0
node --experimental-strip-types example.ts
```
</CodeGroup>

<Warning>
The examples create real resources and may call paid models when pointed at a live endpoint. Read each example before running it. Demo cleanup can delete sessions and their outputs. Download results you need first.
</Warning>

## Additional requirements

- **MCP:** remote MCP servers are currently blocked on hosted Orca, so MCP examples are refused there; write to support@okik.io if you need one.
- **Managed sandbox:** uses [machine time](/plans#machine-time) from your plan.
- **Self-hosted executor:** runs against an Orca server on your own machine; on hosted Orca self-hosted is coming soon. Read the [environment guide](/guides/environments) before connecting one; do not assume any public hostname is supported by stock executor authentication.
- **Resource lifecycle:** creating a vault needs the admin role.
