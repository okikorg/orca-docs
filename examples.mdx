## Run against your endpoint

From a checkout of this repository, configure the same variables as the quickstart:

```bash
export ORCA_BASE_URL="https://YOUR_ORCA_HOST/v1"
export ORCA_API_KEY="YOUR_ORCA_KEY"
export ORCA_MODEL="YOUR_AVAILABLE_MODEL"
```

<CodeGroup>
```bash Python
python3 -m venv .venv
source .venv/bin/activate
python -m pip install openai==3.13.0
python examples/python/basics/quickstart.py
```
```bash TypeScript
cd examples/typescript
npm ci
node --experimental-strip-types basics/quickstart.ts
```
</CodeGroup>

<Warning>
The examples create real resources and may call paid models when pointed at a live endpoint. Read each recipe before running it. Demo cleanup can delete sessions and their outputs. Download results you need first.
</Warning>

## Additional requirements

- **MCP:** set `ORCA_MCP_URL` to your MCP service and use an HTTPS origin approved by your Orca administrator. Do not use the repository's fixture credentials with a real service.
- **Managed sandbox:** your endpoint must have managed execution available. A sandbox image and Docker are requirements for the local example runner, not dependencies of your application client.
- **Self-hosted executor:** runs against an Orca server on your own machine; on hosted Orca self-hosted is coming soon. The recipe requires `ORCA_EXECUTOR_BASE_URL` (a loopback origin) and `ORCA_CODEX_BIN` plus a compatible native Codex binary. Read the [environment guide](/guides/environments) before connecting it; do not assume any public hostname is supported by stock executor authentication.
- **Resource lifecycle:** check that file uploads, skill bundles, and tool credential use are enabled for your account.

## Local contributor runner

For contributors who already have the server built and its development dependencies installed, `python3 examples/run.py` runs the paired examples against temporary local test services. Those test services are not production model or MCP integrations. Missing optional prerequisites are reported as skips, so a successful runner exit does not mean every environment example ran.

```bash
python3 examples/run.py --interface python
python3 examples/run.py --only streaming
```

For normal application development, use the endpoint instructions above rather than the contributor runner.
