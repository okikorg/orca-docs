This guide takes you from a textbook chapter to everything you need for the exam. Cram Coach reads one chapter and gives you a day-by-day plan up to your exam date, flashcards for Anki, a practice test, and answers that each point to the page they came from.

Orca is where it runs. Your chapter goes into a private sandbox that runs only for this session, Cram Coach works through it there, and you download the four files. Tokens cost [OpenRouter's price plus their fee](https://orcapods.ai/pricing), with no markup from us, the harness underneath is built to spend fewer of them, a model call that hits a hiccup is retried for you, and every session shows exactly what it cost. An idea becomes an agent like this in minutes, and that agent becomes part of your product in hours.

Each step below builds on the one before, and the first few are all you need to get your files.

## What it can read

- **Text PDFs only.** If you can select and copy text from the PDF in your viewer, Cram Coach can read it. A scanned PDF has no text to read: Cram Coach says so and stops. It does no OCR.
- **One chapter per run.** If the PDF holds more than one chapter, Cram Coach asks which one you want and stops. Save just the chapter's pages as a new PDF first, for example with your viewer's **Print**, then **Save as PDF**.
- **For now, PDFs under 48 KB.** A bigger file fails before Cram Coach sees it, with `Sandbox file staging failed (environment.files)`. This is a bug in how Orca copies files into a sandbox, and it is being fixed. When it is, the kit and this page will be updated.

<Note>
Most real chapters are bigger than 48 KB for now, since a PDF carries its fonts and images. Check yours with `wc -c < chapter.pdf`: it prints the size in bytes, which must be under 48000.
</Note>

## 2. Copy Cram Coach

Cram Coach is a model and its instructions. It lists no tools: in a sandbox, an agent can already run commands and read and write files, and that is all Cram Coach needs. This is all of it:

<CodeGroup>
```python cram_coach_agent.py
import os

from openai import OpenAI

client = OpenAI(api_key=os.environ["ORCA_API_KEY"], base_url="https://api.orcapods.ai/v1")

coach = client.beta.agents.create(
    name="cram-coach",
    model="orca/openrouter/openai/gpt-5.6-luna",
    instructions=(
        "You are Cram Coach. A student gives you one chapter of a textbook as a PDF in /workspace and the date of "
        "their exam. You turn the chapter into four files under /workspace/outputs: cram-plan.md, flashcards.csv, "
        "practice-test.md and answers.md.\n"
        "\n"
        "Before you write anything:\n"
        "1. Run `date +%Y-%m-%d` in the sandbox for today's date; never assume it. If the student states today's "
        "date, use theirs, since the sandbox clock is UTC.\n"
        "2. Find the exam date in the student's message. If it is missing, unclear or before today, ask for it and "
        "stop; never guess it.\n"
        "3. Run Python to print the calendar you will use: every date from today to the exam date, one line each, "
        "written with datetime as `date.strftime('%A %Y-%m-%d')`, such as Monday 2026-11-02. Build the plan only "
        "from that printed list: copy each date and its weekday from it, and never work out a weekday yourself.\n"
        "4. Find the PDF with `ls /workspace`. If there is none, ask the student to attach it with "
        "`--file chapter.pdf` and stop.\n"
        "5. Run `pip install --quiet pypdf==6.20.1`, then extract the text page by page into /workspace/chapter.txt. "
        "Find each page's printed page number, the number in its header or footer, and put a line "
        "`=== PDF page N, printed page P ===` before each page; where a page shows no number, count on from its "
        "neighbours. If most pages give no text, the PDF is a scan with no "
        "text layer: say so plainly, say that Cram Coach reads only PDFs with selectable text and does no OCR, and "
        "stop. If the PDF holds more than one chapter, say that Cram Coach takes one chapter per run, ask which "
        "one, and stop.\n"
        "6. Read all of chapter.txt. Note the chapter's sections with their numbers, titles and the printed pages "
        "each one spans, and its hardest topics: the most new terms, formulas or steps of reasoning.\n"
        "\n"
        "Use only what the chapter says. Never add facts, examples, numbers or definitions that are not in it, "
        "even ones you know. Every page you write is a printed page read from the markers in chapter.txt: search "
        "chapter.txt for the passage and take the number from the marker above it; never estimate a page.\n"
        "Write plain text: ranges with a hyphen or 'to', and no en or em dashes.\n"
        "\n"
        "The files:\n"
        "- cram-plan.md: a day-by-day plan from today to the exam date, worked backwards from the exam. The exam "
        "day is a light look at the flashcards only. The day before it is the review day: the practice test under "
        "exam conditions, then answers.md, then the cards missed. The days before that cover the chapter, hardest "
        "topics first, in sessions of 25 to 45 minutes, at most two a day; each session names its section, its "
        "pages and one concrete task. If the exam is today or tomorrow, fit the plan into the days there are. "
        "Write each date as weekday and YYYY-MM-DD, copied from the calendar of step 3. Head the plan with the "
        "chapter, today's date, the exam date and the days left.\n"
        "- flashcards.csv: for Anki. 20 to 40 cards, one fact each: key terms, definitions, causes and "
        "effects, how to read the chapter's graphs and tables. End each back with its section in brackets, "
        "such as (3.2). Never write the CSV yourself. First write the cards as JSON to "
        "/workspace/cards.json: a list of objects with a front and a back, each one line of plain text. Then "
        "run exactly this Python, which writes the file and checks that it reads back as your cards:\n"
        "```python\n"
        "import csv, json\n"
        "cards = [[c['front'], c['back']] for c in json.load(open('/workspace/cards.json'))]\n"
        "with open('/workspace/outputs/flashcards.csv', 'w', newline='', encoding='utf-8') as f:\n"
        "    f.write('#separator:Comma\\n#html:false\\n#columns:Front,Back\\n')\n"
        "    csv.writer(f, lineterminator='\\n').writerows(cards)\n"
        "with open('/workspace/outputs/flashcards.csv', encoding='utf-8') as f:\n"
        "    lines = f.read().split('\\n')\n"
        "assert lines[:3] == ['#separator:Comma', '#html:false', '#columns:Front,Back']\n"
        "assert list(csv.reader(lines[3:-1])) == cards\n"
        "print(len(cards), 'cards')\n"
        "```\n"
        "- practice-test.md: 10 to 15 numbered questions in the style of the chapter's own review questions, a mix "
        "of multiple choice (options A to D, one right) and short answer, across every section and weighted to the "
        "hardest topics. At least a third apply the chapter's methods to its own examples, tables or numbers "
        "rather than recall a definition. No answers and no hints.\n"
        "- answers.md: the same numbers, each with the answer, one or two sentences on why, and its source as "
        "section and page, such as Section 3.2, page 61: the page of the sentence or table that states the "
        "answer, found by searching chapter.txt for it. Drop a question you cannot source and renumber.\n"
        "\n"
        "Then check the files with Python: run the flashcards code above again, which must print the card count "
        "with no error; the test and the "
        "answers hold the same 10 to 15 numbers; and the plan's dates run from today to the exam date. For the "
        "weekdays, parse every `Weekday YYYY-MM-DD` in cram-plan.md with a regular expression and compare each "
        "weekday with datetime's `strftime('%A')` for its date; correct every mismatch in the file and run the "
        "check again. Fix what fails, and answer only once every check passes.\n"
        "\n"
        "In chat, reply only with a short summary: the chapter, the days to the exam, the number of cards and "
        "questions, and the four file names. Never paste the files into chat."
    ),
)
print(coach.id)

## 3. Use it

No chapter at hand? Start with the sample: Section 3.1 of the OpenStax textbook Principles of Microeconomics 2e, pages 45 to 51, re-set as a 16 KB text PDF ([source and license](https://github.com/okikorg/orca-kits/blob/main/kits/cram-coach/chapter-source.md)). Download it into this folder:

```bash
curl -L -o chapter.pdf https://github.com/okikorg/orca-kits/raw/main/kits/cram-coach/chapter.pdf
```

To use your own chapter instead, save it in this folder as `chapter.pdf`, and check it's [under 48 KB](#what-it-can-read). The steps from here are the same.

Run Cram Coach on it, with your own exam date in the message:

```bash
orca chat cram-coach --sandbox --file chapter.pdf "My exam is on 2026-10-22."
```

2026-10-22 is the date of the example below, and it has passed by now: put your exam's date in its place. Given a date that's missing or already past, Cram Coach asks for another and stops; answer it in the same session with `orca chat cram-coach --session session_...`.

`--file chapter.pdf` copies your PDF into the session's sandbox, a private machine of its own, at `/workspace/chapter.pdf`. If a file name has spaces, put it in quotes: `--file "Chapter 3.pdf"`.

The dashboard can't attach a PDF to a chat yet, so run Cram Coach from the CLI, your coding agent, or your code.

While it works, Cram Coach:

1. Checks today's date in the sandbox, and prints a calendar from today to your exam.
2. Installs a PDF reader and reads the chapter page by page, noting each page's printed number.
3. Finds the sections and the hardest topics.
4. Writes four files to `/workspace/outputs`, then checks them in code: the flashcards' format, the questions against the answers, and every date and weekday in the plan.

Then it replies with a short summary. A real run on the sample chapter, on 2026-10-15, replied:

```text
Chapter 3, Demand and Supply: 7 days to the exam. Created 24 flashcards and 13 practice questions.

Files:
- `cram-plan.md`
- `flashcards.csv`
- `practice-test.md`
- `answers.md`
```

### Download the four files

The last line names the session: `session session_...`. Use that ID in place of `session_...` to download the files here:

```bash
orca sessions artifacts download session_... --all
```

| File | What it is |
| --- | --- |
| `cram-plan.md` | Your plan from today to the exam, hardest topics first, in sessions of 25 to 45 minutes. The day before the exam is a review day: the practice test, then the answers, then the cards you missed. |
| `flashcards.csv` | 20 to 40 flashcards with a front and a back, ready for Anki. Each back ends with its section, such as (3.1). |
| `practice-test.md` | 10 to 15 questions in the style of the chapter, multiple choice and short answer. No answers. |
| `answers.md` | The answers, each with a reason and its section and page in the chapter. |

Take the practice test before you read the answers.

## Friday 2026-10-16

   D. A shortage of 50 million gallons
```

and its answer, cited to the chapter's page:

```
</Tab>
</Tabs>

### Import the flashcards into Anki

`flashcards.csv` starts with three lines that tell Anki how to read it: comma separated, plain text, and a Front and a Back column. So there is nothing to set up. You need Anki 2.1.54 or later.

In Anki, File, then Import, then choose `flashcards.csv`.

See Anki's guide to [importing text files](https://docs.ankiweb.net/importing/text-files.html) for more.

### Delete the session

When you have your files, delete the session so the sandbox stops:

```bash
orca sessions delete session_... --yes
```

To ask for more first, such as more cards on the hardest section, keep going in the same session, where the chapter is still in the sandbox:

```bash
orca chat cram-coach --session session_... "Make ten more flashcards on the hardest section."
```

Then download again with `orca sessions artifacts download session_... --all`, which saves the files from the newest turn, and delete the session.

## 5. Run it from your own code

Everything so far went through the CLI, which calls the same API your application will. Your code uses the official `openai` package with an Orca API key. If you built Cram Coach from code in step 2, you already have the package: skip to the key.

Install the `openai` package. It needs Python 3.10 or later, or Node 22.18 or later. Check your version first, and update it if it's older:

<CodeGroup>
```bash Python
python3 --version    # 3.10 or later
python3 -m venv .venv
.venv/bin/pip install openai==3.13.0
```
```bash TypeScript
node --version       # 22.18 or later
npm init -y && npm pkg set type=module
npm install openai@7.15.0
```
</CodeGroup>

Then make a key, in the terminal you'll run the program from. This keeps it there as `ORCA_API_KEY` without printing it. A new terminal won't have it, so run this again there.

<CodeGroup>
```bash bash / zsh

```
```fish fish

```
</CodeGroup>

This program uploads your PDF, opens a session with it in the sandbox, streams Cram Coach's reply, saves the four files here, and then deletes the session and the upload:

<CodeGroup>
```python cram_coach.py
import os
import sys
from pathlib import Path

from openai import OpenAI

client = OpenAI(api_key=os.environ["ORCA_API_KEY"], base_url="https://api.orcapods.ai/v1")
agents = client.beta.agents
pdf, exam = sys.argv[1], sys.argv[2]

coach = next(agent for agent in agents.list() if agent.name == "cram-coach")
with open(pdf, "rb") as f:
    uploaded = client.files.create(file=(Path(pdf).name, f), purpose="user_data")
session = agents.sessions.create(
    agent_id=coach.id,
    environment={
        "type": "openai_hosted",
        "files": [{"type": "file_id", "file_id": uploaded.id, "path": "/workspace/chapter.pdf"}],
    },
)
try:
    with agents.sessions.stream(session.id, input=f"My exam is on {exam}.") as stream:
        for event in stream:
            if event.type == "agent.session.turn.output_text.delta":
                print(event.delta, end="", flush=True)
            elif event.type in ("agent.session.turn.failed", "agent.session.turn.cancelled"):
                print("\nThe turn ended:", event.type)
    print()
    for artifact in agents.sessions.artifacts.list(session.id):
        name = Path(artifact.path).name
        agents.sessions.artifacts.content(artifact.id, session_id=session.id).write_to_file(name)
        print("Saved", name)
finally:
    agents.sessions.delete(session.id)
    client.files.delete(uploaded.id)
```
```typescript cram_coach.ts
import { readFile, writeFile } from 'node:fs/promises';
import { basename } from 'node:path';
import OpenAI, { toFile } from 'openai';

const client = new OpenAI({ apiKey: process.env.ORCA_API_KEY, baseURL: 'https://api.orcapods.ai/v1' });
const agents = client.beta.agents;
const [pdf, exam] = process.argv.slice(2);

let coach;
for await (const agent of agents.list()) if (agent.name === 'cram-coach') { coach = agent; break; }
if (!coach) throw new Error('No agent called cram-coach. Copy it first (step 2).');

const uploaded = await client.files.create({ file: await toFile(await readFile(pdf), basename(pdf)), purpose: 'user_data' });
const session = await agents.sessions.create({
  agent_id: coach.id,
  environment: {
    type: 'openai_hosted',
    files: [{ type: 'file_id', file_id: uploaded.id, path: '/workspace/chapter.pdf' }],
  },
});
try {
  for await (const event of agents.sessions.stream(session.id, { input: `My exam is on ${exam}.` })) {
    if (event.type === 'agent.session.turn.output_text.delta') process.stdout.write(event.delta);
    else if (event.type === 'agent.session.turn.failed' || event.type === 'agent.session.turn.cancelled') {
      console.log('\nThe turn ended:', event.type);
    }
  }
  console.log();
  for await (const artifact of agents.sessions.artifacts.list(session.id)) {
    const name = basename(artifact.path);
    const content = await agents.sessions.artifacts.content(artifact.id, { session_id: session.id });
    await writeFile(name, Buffer.from(await content.arrayBuffer()));
    console.log('Saved', name);
  }
} finally {
  await agents.sessions.delete(session.id);
  await client.files.delete(uploaded.id);
}
```
</CodeGroup>

Run it with your PDF and your own exam date in place of 2026-10-22:

## 6. See what it cost, and clean up

Every call is recorded with what it cost, down to the session:

```bash
orca usage --days 1        # today's usage, by the hour
orca billing wallet        # your balance and plan
```

`orca sessions get session_...` shows one session's cost, tokens, and machine time. Do it before you delete the session.

- **Model tokens** are paid from your Orca credit, since Cram Coach's model starts with `orca/`. The run in the example above cost $0.01 in tokens. A longer chapter costs more.
- **Machine time** comes from your plan, since every run has a sandbox. It counts from the sandbox's start until it pauses or you delete the session, not only while Cram Coach works. Runs on the sample chapter, with the session deleted as soon as the files were saved, used one minute each. Sandboxes also need a small balance of credit, your plan's [minimum balance](/plans#paid-work-needs-a-minimum-balance). Delete each session when you have your files.

The numbers for each plan are on the [pricing page](https://orcapods.ai/pricing). See [usage and wallet](/wallet#read-the-wallet-and-your-usage) for the rest.

The CLI also keeps a copy of each PDF you send with `--file` in your organization's files. Find its ID in the list, then delete it:

```bash
orca files list
orca files delete file_... --yes
```

Keep Cram Coach if you like it. To remove everything this page made instead, delete Cram Coach's sessions, then Cram Coach, then the key. Deleting an agent does not delete its sessions.

```bash
orca sessions list --agent cram-coach --all | cut -f1 | xargs -I{} orca sessions delete {} --yes
orca agents delete cram-coach --yes
orca keys list
```

Then revoke the key named `cram-coach` with `orca keys revoke <its id> --yes`, and close the terminal: its `ORCA_API_KEY` still holds the revoked key.
