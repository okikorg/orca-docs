This agent answers a question in five bullets or fewer and cites a source for each one. It uses the built-in `web_search` tool and needs no sandbox, so it uses no machine time.

**You will use:** [web search](/providers#web-search) and [streaming](/guides/streaming).

## Choose a model that searches

`web_search` runs on the agent's own model. Pick a model with built-in web search: on OpenRouter that is an OpenAI, Anthropic, Google, Perplexity, or xAI model. Other models may answer without searching, and the search then fails with `no_search`. Vercel AI Gateway and CheaperInference models cannot search at all, and saving the agent is refused.

On Orca credit, each search costs the provider's search fee plus your model's tokens for reading the results. See [what a search costs](/providers#what-a-search-costs).

```python
"""Ask a research question and print the cited answer."""

import os
import sys

import openai

client = openai.OpenAI(api_key=os.environ["ORCA_API_KEY"], base_url=os.environ["ORCA_BASE_URL"])
agents = client.beta.agents

INSTRUCTIONS = """\
You research the user's question on the web and answer in five bullets or fewer.
Search before you answer. Cite a source link for every bullet.
If the sources disagree, say so. If you find nothing reliable, say that
instead of guessing. Do not use emojis."""

question = sys.argv[1] if len(sys.argv) > 1 else "What changed in the latest stable Postgres release?"

agent = session = None
try:
    agent = agents.create(
        model=os.environ["ORCA_MODEL"],
        name="researcher",
        instructions=INSTRUCTIONS,
        tools=[{"type": "web_search"}],
    )
    session = agents.sessions.create(agent_id=agent.id, environment={"type": "none"})

    with agents.sessions.stream(session.id, input=question) as stream:
        for event in stream:
            if event.type == "agent.session.turn.completed":
                print("turn:", event.turn.status)

    # Newest first: show what was searched, then the answer.
    items = list(reversed(agents.sessions.items.list(session.id, limit=50).data))
    for item in items:
        if item.type == "web_search_call":
            action = getattr(item, "action", None)
            print("searched:", getattr(action, "query", None), item.status)
    for item in items:
        if item.type == "message" and item.role == "assistant":
            for part in item.content or []:
                if getattr(part, "text", None):
                    print(part.text)
finally:
    # Delete each resource on its own, so one failed delete does not skip the rest.
    if session:
        try:
            agents.sessions.delete(session.id)
        except openai.APIError:
            pass
    if agent:
        try:
            agents.delete(agent.id)
        except openai.APIError:
            pass
    client.close()
```

/** Ask a research question and print the cited answer. */
import OpenAI from 'openai';

const client = new OpenAI({ apiKey: process.env.ORCA_API_KEY!, baseURL: process.env.ORCA_BASE_URL! });
const agents = client.beta.agents;

const INSTRUCTIONS = `You research the user's question on the web and answer in five bullets or fewer.
Search before you answer. Cite a source link for every bullet.
If the sources disagree, say so. If you find nothing reliable, say that
instead of guessing. Do not use emojis.`;

const question = process.argv[2] ?? 'What changed in the latest stable Postgres release?';

let agent: { id: string } | undefined;
let session: { id: string } | undefined;
try {
  agent = await agents.create({
    model: process.env.ORCA_MODEL!,
    name: 'researcher',
    instructions: INSTRUCTIONS,
    tools: [{ type: 'web_search' }],
  });
  session = await agents.sessions.create({ agent_id: agent.id, environment: { type: 'none' } });

  for await (const event of agents.sessions.stream(session.id, { input: question })) {
    if (event.type === 'agent.session.turn.completed') console.log('turn:', event.turn.status);
  }

  // Newest first: show what was searched, then the answer.
  const items = [...(await agents.sessions.items.list(session.id, { limit: 50 })).data].reverse();
  for (const item of items as any[]) {
    if (item.type === 'web_search_call') console.log('searched:', item.action?.query, item.status);
  }
  for (const item of items as any[]) {
    if (item.type === 'message' && item.role === 'assistant') {
      for (const part of item.content ?? []) if (part.text) console.log(part.text);
    }
  }
} finally {
  // Delete each resource on its own, so one failed delete does not skip the rest.
  if (session) await agents.sessions.delete(session.id).catch(() => {});
  if (agent) await agents.delete(agent.id).catch(() => {});
}

Keep the agent instead of deleting it if you will ask it more questions. Create it once, store its ID, and open a new session per question.

## Make it yours

- **Limit the sources.** `web_search` accepts `allowed_domains`, for example your own docs site or a set of trusted publishers.
- **Ask follow-ups.** Send the next question to the same session; the agent remembers what it already found.
- **Check failed searches.** A failed search leaves a `web_search_call` item with `status` `incomplete` and an `error`. The turn still goes on. See [when a search fails](/providers#when-a-search-fails).
- **Quote exact text.** Orca does not fetch the pages behind the results. If the agent must quote a page word for word, add a [function tool](/guides/function-tools) that fetches it.
