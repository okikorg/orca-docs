Orca runs AI agents for you in the cloud. You describe an agent once: a model, its instructions, and the tools it may use. Orca does the rest. It runs every conversation to the end, searches the web, runs code in a private sandbox when the job needs one, and keeps the whole history. Your code talks to Orca with the official `openai` package, so there is no new SDK to learn.

In about ten minutes you'll have a research agent of your own that looks things up and cites its sources, give it a sandbox to work in, and then hand the controls to your coding agent and your own code.

<Tip>
**No account yet?** [Sign up](https://app.orcapods.ai/sign-up) first. New accounts get [free credit](/wallet#the-signup-credit-needs-a-card) once they add a card, which is never charged, and every step on this page runs on it.
</Tip>

You need a terminal on macOS or Linux. Python or Node is only needed to build the agent from code (step 2) and in step 6. Only step 4 uses machine time; everything else is model tokens and web searches on your credit.

## 1. Install the CLI and sign in

```bash
curl -fsSL https://orcapods.ai/install.sh | sh
orca --version
```

The script installs a single `orca` binary to `~/.local/bin`. If your shell then says `orca: command not found`, add that folder to your `PATH` as the script suggests, and open a new terminal. On Windows, download the binary from the [releases page](https://github.com/okikorg/orca-cli/releases). Copying a kit needs CLI 1.4.0 or later: an older CLI updates itself with `orca update`.

```bash
orca login
```

It prints a one-time code and a link to the Orca dashboard. Open the link, sign in, check that the code matches, and choose **Approve**. The CLI then prints "Logged in to Orca as" your role and organization. It works the same over SSH and inside a coding agent, which relays the code and the link to you.

Check your credit:

```bash
orca billing wallet
```

`balance` is your Orca credit. A new account's signup credit is free credit, unlocked once the person who created the organization adds a card in the dashboard's **Wallet**; the card is never charged, and the CLI cannot add one. Until then `orca billing wallet` shows free credit as locked. The amount is on the [pricing page](https://orcapods.ai/pricing); see [the signup credit needs a card](/wallet#the-signup-credit-needs-a-card).

## 2. Get your first agent

Your first agent is **Scout**, a research assistant that searches the web and answers with its sources. This is all of it:

<CodeGroup>
```python scout_agent.py
import os

from openai import OpenAI

client = OpenAI(api_key=os.environ["ORCA_API_KEY"], base_url="https://api.orcapods.ai/v1")

scout = client.beta.agents.create(
    name="scout",
    model="orca/openrouter/openai/gpt-5.6-luna",
    instructions=(
        "You are Scout, a research assistant. Answer in a few short paragraphs or a short list.\n"
        "Search the web when the answer depends on facts that change, such as releases, versions, "
        "prices or news, and cite each source with its link.\n"
        "Newer releases may exist than you remember: for anything \"latest\", search without naming a version, "
        "and trust what you find over what you remember.\n"
        "If the sources disagree, or you cannot find an answer, say so instead of guessing."
    ),
    tools=[{"type": "web_search"}],
)
print(scout.id)
```
```typescript scout_agent.ts
import OpenAI from 'openai';

const client = new OpenAI({ apiKey: process.env.ORCA_API_KEY, baseURL: 'https://api.orcapods.ai/v1' });

const scout = await client.beta.agents.create({
  name: 'scout',
  model: 'orca/openrouter/openai/gpt-5.6-luna',
  instructions:
    'You are Scout, a research assistant. Answer in a few short paragraphs or a short list.\n' +
    'Search the web when the answer depends on facts that change, such as releases, versions, ' +
    'prices or news, and cite each source with its link.\n' +
    'Newer releases may exist than you remember: for anything "latest", search without naming a version, ' +
    'and trust what you find over what you remember.\n' +
    'If the sources disagree, or you cannot find an answer, say so instead of guessing.',
  tools: [{ type: 'web_search' }],
});
console.log(scout.id);
```
</CodeGroup>

A model, its instructions, and one tool. There is no loop to write, no search API to call, and no history to store: Orca runs each conversation, calls the search whenever the model asks for it, and keeps every message. The model name also says who pays. `orca/openrouter/<id>` runs on your Orca credit; `<provider>/<id>`, such as `anthropic/claude-sonnet-4-5`, runs on your own key for that provider. See [models and provider keys](/providers).

## 3. Ask it something

Ask Scout something it has to look up:

```bash
orca chat scout "What's new in the latest Python release? Cite your sources."
```

Scout searches the web, then streams its answer into your terminal, with a link for each source.

To have a conversation, run `orca chat scout` with no question. You're now chatting with Scout, and it remembers what you said. Try a question, then a follow-up:

```bash
orca chat scout
```

```text
Which three Python web frameworks are most used today?
Compare the first two in a short table.
```

Ctrl-C leaves the chat. On the way out it prints `session session_...`: a session is one conversation, and Orca keeps it. `orca chat scout --session session_...` (with your session's ID) picks it up again tomorrow, and the [Sessions page](https://app.orcapods.ai/sessions) in the dashboard shows every turn.

## 4. Give it a sandbox

Add `--sandbox`, and the conversation runs in a sandbox, a private machine of its own where Scout can run code and save files. Anything it saves in `/workspace/outputs` is kept for you to download:

```bash
orca chat scout --sandbox "Look up the release dates of the last five Python versions, then use Python to save them to /workspace/outputs/python-releases.csv, with the number of days between each release."
```

Scout searches the web, writes a short Python script, runs it in the sandbox, and tells you what it saved. The last line names the session: `session session_...`. Use that ID in place of `session_...` to download the file here, then delete the session to shut the sandbox down:

```bash
orca sessions artifacts download session_... --all
orca sessions delete session_... --yes
```

`--all` saves every file from Scout's last turn here, so you now have `python-releases.csv`. To keep working in the same sandbox first, with the files where Scout left them, run `orca chat scout --session session_...` before you delete it. A sandbox that sits idle pauses itself and stops using machine time, with its files kept for when the session needs it again.

To hand Scout a file of yours, add `--file data.csv` to `orca chat`: it lands in the sandbox at `/workspace/data.csv`.

## 6. Run it from your own code

Everything so far went through the CLI, which calls the same API your application will. Your code uses the official `openai` package with an Orca API key. If you built Scout from code in step 2, you already have the package: skip to the key.

Install the `openai` package. It needs Python 3.10 or later, or Node 22.18 or later. Check your version first, and update it if it's older:

<CodeGroup>
```bash Python
python3 --version    # 3.10 or later
python3 -m venv .venv
.venv/bin/pip install openai==3.13.0
```
```bash TypeScript
node --version       # 22.18 or later
npm init -y && npm pkg set type=module
npm install openai@7.15.0
```
</CodeGroup>

Then make a key, in the terminal you'll run the program from. This keeps it there as `ORCA_API_KEY` without printing it. A new terminal won't have it, so run this again there.

<CodeGroup>
```bash bash / zsh
export ORCA_API_KEY=$(orca keys create start-here </dev/null)
```
```fish fish
set -x ORCA_API_KEY (orca keys create start-here </dev/null)
```
</CodeGroup>

This program finds Scout, opens a session, and streams one answer:

<CodeGroup>
```python scout.py
import os

from openai import OpenAI

client = OpenAI(api_key=os.environ["ORCA_API_KEY"], base_url="https://api.orcapods.ai/v1")
agents = client.beta.agents

scout = next(agent for agent in agents.list() if agent.name == "scout")
session = agents.sessions.create(agent_id=scout.id, environment={"type": "none"})
try:
    with agents.sessions.stream(session.id, input="What is the latest Node.js LTS release? Cite your source.") as stream:
        for event in stream:
            if event.type == "agent.session.turn.output_text.delta":
                print(event.delta, end="", flush=True)
            elif event.type in ("agent.session.turn.failed", "agent.session.turn.cancelled"):
                print("\nThe turn ended:", event.type)
    print()
finally:
    agents.sessions.delete(session.id)
```
```typescript scout.ts
import OpenAI from 'openai';

const client = new OpenAI({ apiKey: process.env.ORCA_API_KEY, baseURL: 'https://api.orcapods.ai/v1' });
const agents = client.beta.agents;

let scout;
for await (const agent of agents.list()) if (agent.name === 'scout') { scout = agent; break; }
if (!scout) throw new Error('No agent called scout. Get it first (step 2).');

const session = await agents.sessions.create({ agent_id: scout.id, environment: { type: 'none' } });
try {
  for await (const event of agents.sessions.stream(session.id, { input: 'What is the latest Node.js LTS release? Cite your source.' })) {
    if (event.type === 'agent.session.turn.output_text.delta') process.stdout.write(event.delta);
    else if (event.type === 'agent.session.turn.failed' || event.type === 'agent.session.turn.cancelled') {
      console.log('\nThe turn ended:', event.type);
    }
  }
  console.log();
} finally {
  await agents.sessions.delete(session.id);
}
```
</CodeGroup>

<CodeGroup>
```bash Python
.venv/bin/python scout.py
```
```bash TypeScript
node --experimental-strip-types scout.ts
```
</CodeGroup>

Scout lives on Orca, so your code only opens a session and reads the answer. [Build with the API](/build-with-the-api) explains each call.

## 7. See what it cost, and clean up

Every call is recorded with what it cost, down to the session:

```bash
orca usage --days 1        # today's usage, by the hour
orca billing wallet        # your balance and plan
```

`orca sessions get session_...` shows one session's cost, tokens, and machine time.

- **Model tokens and web searches** on an Orca credit model are paid from your credit. On your own provider key, that provider bills you.
- **Sessions without a sandbox use no machine time.** On this page, only step 4 used any.
- **Sandboxes use [machine time](/plans#machine-time)** from your plan. They also need a small balance of Orca credit, your plan's [minimum balance](/plans#paid-work-needs-a-minimum-balance), since the agent's model calls in the sandbox run on credit too. Delete a sandbox session when you are done with it.

The numbers for each plan, the signup credit, the minimum balance, and free credit's price ceiling and daily limit are on the [pricing page](https://orcapods.ai/pricing). Free credit pays only for models at or under the price ceiling, up to the daily limit; see [what free credit pays for](/wallet#what-free-credit-pays-for). See [usage and wallet](/wallet#read-the-wallet-and-your-usage) for the rest.

Keep Scout if you like it. To remove everything this page made instead, delete Scout's sessions, then Scout, then the key. Deleting an agent does not delete its sessions.

```bash
orca sessions list --agent scout --all | cut -f1 | xargs -I{} orca sessions delete {} --yes
orca agents delete scout --yes
orca keys list
```

Then revoke the key named `start-here` with `orca keys revoke <its id> --yes`, and close the terminal: its `ORCA_API_KEY` still holds the revoked key.
